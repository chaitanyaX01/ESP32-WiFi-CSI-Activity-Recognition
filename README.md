# WiSense AI

Device-Free Human Activity Recognition using Wi-Fi CSI and ESP32-S3.

## Activities
- Empty
- Standing
- Walking
- Sitting

## Hardware
- ESP32-S3 N16R8
- 2.4 GHz Wi-Fi router
- MacBook

## ML Models
- Random Forest
- SVM

## Current Random Forest Result
- Validation Accuracy: 80.06%
- Test Accuracy: 82.60%

## Pipeline

ESP32-S3 → Wi-Fi CSI → Python preprocessing → Feature extraction → ML model → Real-time dashboard
